### Anthropic — Claude Duet, agent proactif en préversion [NOUVEAU]
- Fait : application autonome tournant sur Claude Opus 5.5 ; surveille e-mails, agendas et Slack, envoie un brief matinal, s'exécute dans le cloud appareil éteint. Plus de 6 000 outils connectés ; achats possibles via Link (Stripe) et Shop Pay ; approbation demandée avant envoi de message, paiement ou suppression ; certaines actions (opérations boursières, virements entre comptes) bloquées même avec approbation. Accès par liste d'attente pour abonnés Pro et Max aux États-Unis, sans surcoût, les tâches de fond consommant les quotas.
- Sources : « Claude Duet », claude.com, via TLDR AI 22/10/2026 ; « Anthropic joins the AI agent race with Claude Duet », via TLDR 22/10/2026 ; AlphaSignal 22/10/2026. URL : https://claude.com/resources/articles/claude-duet [source primaire non fetchée ; 3 relais concordants].

### Anthropic — Agent Skills cédé à l'Agentic AI Foundation [NOUVEAU]
- Fait : le 22/10/2026, Anthropic transfère le standard ouvert Agent Skills (dossier avec SKILL.md), le nom, le logo, l'organisation GitHub et le domaine agentskills.io à l'AAIF (Linux Foundation, cofondée en 2025 avec Block et OpenAI, qui héberge déjà MCP). Chiffres Anthropic : plus de 70 plateformes d'agents l'ont adopté (dont ChatGPT, Cursor, GitHub Copilot, VS Code), ~1 million de skills publiés, ~280 millions d'installations. Feuille de route : versions numérotées, processus de propositions, recommandations de sécurité.
- Sources : « Donating Agent Skills to the Agentic AI Foundation », Anthropic, 22/10/2026, https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation.
