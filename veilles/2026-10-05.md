## ⚡ À retenir (importance 3)

### [SUITE de 02/10] OpenAI — crise sécurité : 3 licenciements confirmés + GPT-6.1 Astra mis de côté

- **Fait :** Les 3 licenciements de chercheurs sécurité d'OpenAI (01/10) sont confirmés par 2 sources indépendantes (WSJ + TLDR AI 02/10). Motif précis révélé : **partage d'informations confidentielles avec un groupe de sécurité IA tiers**. Élément entièrement nouveau : OpenAI a **mis de côté (« shelved ») le lancement de GPT-6.1 Astra spécifiquement pour raisons de sécurité** — premier modèle frontier retardé post-lancement pour ce motif explicite. Le 03/10, un **4e départ** — cette fois volontaire — est publié sur TechCrunch : un employé sécurité quitte en déclarant que **« la culture d'OpenAI est brisée »**. Séquence sur 22 jours : Coxon (11/09), Benton+Engels→METR (12/09), pause entraînement (28/09), licenciements ×3 (01/10), shelve d'Astra (02/10), 4e départ (03/10).
- **Enjeu :** La décision de retarder un modèle frontier déjà lancé pour raisons de sécurité est sans précédent récent. Elle place OpenAI face à une contradiction publique avec son narratif de "pacing" cosigné par Altman le 12/09. Les RFIs EU AI Office (deadline 29/09) ont en toile de fond exactement ce type de questions (Art. 9 GPAI). Pour les acheteurs publics FR/EU : la concomitance licenciements sécurité + shelve modèle est un argument supplémentaire pour les clauses d'audit indépendant dans les marchés IA.
- **Sources :** TLDR AI 02/10/2026 (WSJ relayé) ; TechCrunch 03/10/2026 [Confiance : **élevée** — 2+ sources concordantes]

### [NOUVEAU] Anthropic — distillation Claude par DeepSeek + 6 développeurs chinois incl. Xiaomi

- **Fait :** Anthropic a accusé publiquement **DeepSeek et six autres développeurs chinois** — dont **Xiaomi** (MiMo), **Kimi** (Moonshot) et quatre autres — d'avoir distillé ses modèles Claude à grande échelle. Pour le seul cas Xiaomi : **plus de 400 000 échanges Claude** ont été routés via les outils de coding **OpenClaw et OpenCode** entre **mars et avril 2026**, utilisés ensuite comme données d'entraînement pour MiMo-V2.6-Pro. Xiaomi n'a pas répondu publiquement à cette accusation au 05/10. Simultanément, Anthropic publie une analyse de sécurité de GLM-5.3 (Z.ai / Zhipu) : le modèle atteint 12 % de succès sur ExploitBench (vs 14 % pour Mythos), et $20,40 de tokens GLM-5.3-Flash suffisent à identifier un CVE Chrome récent.
- **Enjeu :** L'accusation de distillation massive est une première à cette échelle contre des acteurs chinois nommément cités par un lab frontière US. Elle alimente le débat sur les contrôles à l'export et soulève une question de droit applicable (Art. 5(1)(d) AI Act : restrictions sur données d'entraînement contrefaisant des droits). Pour l'écosystème FR : Mistral et ses partenaires (IBM, Microsoft, etc.) utilisent des APIs API ouvertes — la même vulnérabilité structurelle existe si des tiers routent des appels. L'analyse GLM-5.3 est un signal défensif : les capacités cyber des modèles open-weights chinois sont maintenant au niveau des modèles fermés US.
- **Sources :** The Batch / DeepLearning.AI 02/10/2026 ; The Next Web 02/10/2026 [Confiance : **élevée** — Anthropic source primaire relayé The Batch]

### [NOUVEAU] Xiaomi MiMo-V2.6 Pro — premier open-weights à dépasser GPT-6 Sol sur l'Intelligence Index

- **Fait :** Xiaomi lance **MiMo-V2.6-Pro** et sa variante Flash, deux modèles open-weights **MIT**. MiMo-V2.6-Pro **prend la tête de l'Intelligence Index d'Artificial Analysis** (score 46, ex æquo avec Grok 4.7 set to high reasoning) — premier modèle open-weights à atteindre ce niveau, à **$0,13/tâche** (vs $0,39 pour GPT-6 Sol). Architecture MoE : **1,02T params / 42B actifs**. MiMo-V2.6-Flash (309B/15B actifs) prend la tête du Vals Index (59,58 %). Input : texte, images, vidéo, audio (1M tokens). Output : 128K tokens, 44,4 tok/s. Nouveauté de la recette d'entraînement : reward quality-checker sur le code (checklist qualité en plus du test pass/fail). Xiaomi publie aussi 7 000+ environnements RL et le code d'entraînement. Coût total déclaré : $2,6 M pour Pro, $0,9 M pour Flash.
- **Enjeu :** Un modèle open-weights à ce niveau de performance, licence MIT, pour moins de $3 M d'entraînement total, change radicalement la référence de coût pour un modèle souverain. Pour les équipes d'IA publique FR/EU : MiMo-V2.6-Pro peut être fine-tuné, auto-hébergé (SecNumCloud), sans dépendance API US ou CN — à condition de maîtriser les risques de distillation (cf. accusation Anthropic ci-dessus).
- **Sources :** The Batch / DeepLearning.AI 02/10/2026 ; Artificial Analysis ; Hugging Face [Confiance : **élevée** — benchmarks indépendants]

### Écosystème mondial

**[NOUVEAU] DeepSeek V4.1-Flash — architecture radicalement nouvelle — 02/10/2026**

DeepSeek publie **V4.1-Flash**, premier modèle de la série V4.1, avec une architecture **encoder-decoder MoE** entièrement redessinée. Module mémoire dédié de 196B params s'ajoute aux 552B de backbone ; 8B actifs en lecture / 16B en génération. Cache KV réduit à **890 octets/token** (×437 vs DeepSeek V1, ×4 vs V4-Flash) : seules 4 couches sur 40 calculent un cache complet, les autres en empruntent via YOCO modifié. Benchmark : 1er sur AutomationBench-AA (68,9 %) — devant GPT-6 Astra (68,5 %). Score Intelligence Index : 39 (vs 36 pour V4-Pro). Prix : **$0,30/$1,20** input/output (peak), moitié prix hors-peak. Licence : **MIT open-weights**. [Source : The Batch / DeepLearning.AI 02/10/2026 ; arXiv:2609.19969 — Confiance : **élevée**]

**[NOUVEAU] Anthropic — $100 M pour former 10 000 ingénieurs IA enterprise — 02/10/2026**

Anthropic annonce un investissement de **$100 M** dédié à former **10 000 ingénieurs** pour réduire le déficit de talents IA en entreprise. Objectif déclaré : accélérer le déploiement enterprise des modèles Claude en formant les équipes techniques clientes. [Source : Anthropic newsroom 02/10/2026 — Confiance : **élevée** — source primaire]

**[NOUVEAU] Google Gemini 3.8 Live + Live Extended Thinking — voix temps réel — ~30/09/2026**

Google lance **Gemini 3.8 Live** et **Gemini 3.8 Live Extended Thinking**, modèles speech-to-speech pour agents voix temps réel. Basés sur Gemini 3 Pro. Live Extended Thinking : rang 1 sur le Speech-to-Speech Index (82,6 %) ; Live : rang 2 sur le Speech Agent Arena (préféré par les utilisateurs pour les tâches conversationnelles) et rang 5 Speech-to-Speech Index (76 %). Tarifs : $0,75/M tokens texte input, $3/M audio input, $4,50/M texte output, $12/M audio output. **Gemini 3.8 Live = modèle voix le moins cher ($0,84/h audio)** selon Artificial Analysis. Tout l'audio watermarqué SynthID. Disponible API, Vertex AI, Google AI Studio. [Source : The Batch / DeepLearning.AI 02/10/2026 — Confiance : **élevée** — 1 source ; date de lancement à confirmer en source primaire Google]

**[NOUVEAU] Microsoft MAI-Transcribe + MAI-Voice — rang 1 Artificial Analysis audio — 02/10/2026**

Microsoft lance **MAI-Transcribe-2-Streaming** (transcription temps réel, 60 langues, détection automatique de langue) et **MAI-Voice-2.1 / MAI-Voice-2.1-Flash** (TTS/voix conversationnelle 23 langues, 26 locales). MAI-Transcribe-2-Streaming se hisse **rang 1 sur Artificial Analysis audio understanding**. Signal concurrentiel direct sur Gradium (FR) et ElevenLabs.
