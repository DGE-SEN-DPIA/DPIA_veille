Impact sur les déploiements en cours (DINUM "L'Assistant" 1 M agents, SecNumCloud) : continuité probable mais avec une doctrine cybersécurité plus stricte. Watch : décret de création formel d'ARIANE ; périmètre vs ANSSI ; impact sur marchés publics IA automne 2026.

**DreamX-Phi 1.0** (arXiv 2608.13489 — Alibaba, 13/08/2026) 🔴 FRAIS
World model action-conditionné pour la manipulation robotique : génère des séquences vidéo prédictives à partir d'instructions en langage naturel + actions motrices, puis les utilise comme guide de politique. Trending #1 HuggingFace Papers le 14/08. Signal fort : Alibaba + robotique + world models convergent avec la thèse AMI Labs (I-JEPA) et GENE-26.5 (Genesis AI).
→ arxiv.org/abs/2608.13489

**Paradigme World Action Models / WAMs** (arXiv 2605.12090 — mai 2026)
Formalise les WAMs : distribution jointe états futurs + actions (vs VLAs classiques qui conditionnent uniquement l'action). Référence théorique pour DreamX-Phi 1.0, Kairos 3.1, Gemini Robotics 2. Compatible avec la thèse world models de LeCun/AMI Labs.
→ arxiv.org/abs/2605.12090

**HALO** (arXiv 2602.21157) — VLA unifiée pour raisonnement embodied multimodal en chaîne de pensée. Trending HF Papers mi-août.

**VLA-JEPA** (arXiv 2602.10098) — VLA enrichie d'un world model latent (inspiration I-JEPA). Potentiellement proche de l'architecture visée par AMI Labs.

**ARIS** (Shanghai Jiao Tong) — harness open-source pour recherche autonome multi-modèle, collaboration adversariale inter-modèles. Signal : écosystème outillage recherche scientifique automatisée (convergence avec Discovery Loop).
