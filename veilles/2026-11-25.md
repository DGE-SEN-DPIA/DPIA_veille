### NVIDIA — Jensen Huang réintégré PDG [SUITE de 24/11, dernière mention le 24/11]
- Fait : le 23/11/2026, le conseil réintègre Huang comme président-directeur général et administrateur, effet immédiat, à l'unanimité, après avis de hauts responsables du gouvernement américain selon lesquels la décision ne présente pas de risque pour la sécurité nationale. Harvey C. Jones reste président du conseil ; Colette Kress, PDG par intérim depuis le 12/11, reste directrice financière. Un comité d'administrateurs indépendants enquête sur des informations selon lesquelles Huang aurait été ciblé par une opération de renseignement étranger ; un second comité supervise conformité commerciale, exports et sécurité nationale ; recherche d'un Chief Compliance Officer. Le communiqué ne mentionne aucune condition formelle. TLDR (24/11, citant CNBC) attribue la décision à une promesse personnelle de Trump et à la chute du cours ; le WSJ note que les enquêtes autour de Huang se poursuivent [attribution politique : médias, non confirmée par NVIDIA]. Contradiction levée : le conseil écartait ce retour le 17/11/2026.
- Sources : NVIDIA, « NVIDIA Board Reinstates Jensen Huang as President, CEO, and Board Director » — 23/11/2026 — https://nvidianews.nvidia.com/news/nvidia-board-reinstates-jensen-huang-as-president-ceo-and-board-director ; CNBC via TLDR — 23/11/2026 — https://www.cnbc.com/2026/11/23/trump-nvidia-jensen-huang.html ; WSJ via TLDR — 24/11/2026.

### Amazon / Decart — acquisition confirmée [SUITE de 24/11, dernière mention le 24/11]
- Fait : Amazon acquiert la technologie de la Decart Optimization Stack (DOS, logiciel d'optimisation des modèles sur matériel NVIDIA, Amazon et Google), l'équipe fondatrice et les chercheurs de Decart (Israël, vidéo générative temps réel), pour 7,5 Md$. Annonce officielle par billet d'Amazon (Peter DeSantis, 23/11/2026) ; le montant vient de Bloomberg et n'est pas confirmé par les parties. Enjeu : faciliter l'exécution de charges sur Trainium, qu'Amazon prévoit de vendre à des tiers face à NVIDIA.
- Sources : TechCrunch, « Amazon snaps up Decart's AI optimization tech for $7.5B… » — 23/11/2026 — https://techcrunch.com/2026/11/23/amazon-snaps-up-decarts-ai-optimization-tech-for-7-5b-as-it-prepares-to-sell-trainium-chips/ ; Amazon (blog DeSantis) via TechCrunch [montant : 1 source].

### Anthropic — Claude Ship [NOUVEAU]
- Fait : trois agents pour pull requests GitHub : Code Review (revue de diff, disponible pour tous), PR Steward (bêta : corrige CI, conflits, commentaires, surveille la PR jusqu'à 7 jours), Claude Approvals (bêta : approuve les PR routinières selon un fichier de politique du dépôt). Activation via `/ship` ; sur Team/Enterprise, activation à l'échelle du dépôt par les admins ; les règles de branche restent décisives. AlphaSignal signale aussi des plugins Claude (10 000+ outils, tous plans) [1 source].
- Sources : Anthropic, « Introducing Claude Ship » — 24/11/2026 — https://claude.com/resources/articles/introducing-claude-ship ; AlphaSignal — 24/11/2026.
