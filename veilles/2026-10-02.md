### Écosystème mondial

**[NOUVEAU] Amazon Strands Decider 2B — décision open source auto-hébergeable — 01/10/2026**

Amazon publie **Strands Decider 2B**, modèle de décision **open source, gratuit, auto-hébergeable et reproductible**. Répond directement à l'API Decisions d'OpenAI (GPT-6 Luna, 150 ms, couverte 01/10) et positionne Amazon sur le segment logique applicative IA. Argument vendor-lock-out explicite. [Source : VentureBeat 01/10/2026 — Confiance : élevée]

**[NOUVEAU] Praxis-1 (Runway) — world action model pour robots réels — 01/10/2026**

**Runway** publie **Praxis-1**, un **world action model** qui transforme le pretraining vidéo générique de Runway en capacités de contrôle pour robots physiques réels. Accès : partenaires early access sur leur propre hardware ; accès public dans les prochains mois. Méthode : pretraining vidéo → fine-tuning contrôle robotique. Signal : Runway, acteur de la génération vidéo, entre dans le segment IA physique avec une approche distincte des fondations VLA classiques. Concurrent de Physical Intelligence (PI), Isaac GR00T (NVIDIA), τ₀-VLA. [Source : runway.com/research ; TLDR AI 01/10/2026 — Confiance : élevée]

**[NOUVEAU] DeepSeek — abstraction CUDA / Huawei Ascend — 01/10/2026**

DeepSeek développe une **couche d'abstraction entre ses modèles et le hardware GPU** permettant de cibler indifféremment NVIDIA CUDA ou les puces **Huawei Ascend**. Objectif : réduire le coût de migration entre écosystèmes hardware. Si réussie, cette couche affaiblirait structurellement l'effet de verrouillage CUDA et donc l'efficacité des export controls GPU américains. Signal direct pour les analyses de politique de containment technologique UE/US. [Source : geopolitechs.org + TLDR AI 01/10/2026 — Confiance : élevée]
